# CO-CRAFT Token-Level Method

## 1. Goal

CO-CRAFT-Token is a teacher-free token-importance mechanism for CRAFT. It keeps the CRAFT outer objective:

\[
\widetilde S_c - f^*(\widetilde S_r),
\]

and derives token weights from the centered optimal \(f\)-critic:

\[
a_f(\Delta)=f'(e^\Delta)-f'(1).
\]

The main idea is:

\[
\boxed{
\text{outer sequence-level asymmetry: } f^*
}
\]

\[
\boxed{
\text{inner token-level importance: } f'
}
\]

Thus, CO-CRAFT-Token uses the same \(f\)-divergence principle for both sequence-level rejected-score transformation and token-level weighting.

---

## 2. Self-Play Setting

For each prompt \(x\), we have:

\[
y=[y_1,\ldots,y_T]
\]

as the chosen response from SFT data, and:

\[
y'=[y'_1,\ldots,y'_{T'}]
\]

as the rejected response generated by the frozen self-play checkpoint:

\[
y'\sim \pi_{\theta_k}(\cdot\mid x).
\]

Here:

- \(\pi_{\theta_k}\): frozen model at self-play iteration \(k\),
- \(\pi_\theta\): model being optimized,
- \(y\): chosen response,
- \(y'\): self-generated rejected response.

---

## 3. CRAFT Outer Objective

Without token weights, the chosen and rejected scores are:

\[
S_c
=
\sum_{t=1}^{T}
\beta
\log
\frac{
\pi_\theta(y_t\mid x,y_{<t})
}{
\pi_{\theta_k}(y_t\mid x,y_{<t})
},
\]

\[
S_r
=
\sum_{j=1}^{T'}
\beta
\log
\frac{
\pi_\theta(y'_j\mid x,y'_{<j})
}{
\pi_{\theta_k}(y'_j\mid x,y'_{<j})
}.
\]

CRAFT replaces the symmetric score:

\[
S_c-S_r
\]

with the asymmetric score:

\[
S_c-f^*(S_r).
\]

The derivative with respect to the rejected score is:

\[
\frac{\partial}{\partial S_r}
\left(S_c-f^*(S_r)\right)
=
-{f^*}'(S_r).
\]

Therefore, if \(|{f^*}'(S_r)|>1\), CRAFT gives stronger gradients to hard rejected responses than the linear objective.

---

## 4. Token-Level Cross-Prefix Distributions

For a chosen token position \(t\), define:

\[
P_t^c
=
\pi_{\theta_k}(\cdot\mid x,y_{<t}),
\]

\[
Q_t^c
=
\pi_{\theta_k}(\cdot\mid x,y'_{<a(t)}).
\]

Here:

- \(P_t^c\): next-token distribution under the chosen prefix,
- \(Q_t^c\): next-token distribution under the aligned rejected prefix,
- \(a(t)\): alignment map from chosen token position to rejected-prefix position.

The simplest implementation uses:

\[
a(t)=t,
\qquad
t\leq \min(T,T').
\]

For a rejected token position \(j\), define:

\[
P_j^r
=
\pi_{\theta_k}(\cdot\mid x,y'_{<j}),
\]

\[
Q_j^r
=
\pi_{\theta_k}(\cdot\mid x,y_{<b(j)}).
\]

---

## 5. Token-Level Log-Ratio

For chosen token \(y_t\):

\[
\Delta_t^c
=
\log
\frac{
P_t^c(y_t)
}{
Q_t^c(y_t)
}
=
\log
\frac{
\pi_{\theta_k}(y_t\mid x,y_{<t})
}{
\pi_{\theta_k}(y_t\mid x,y'_{<a(t)})
}.
\]

For rejected token \(y'_j\):

\[
\Delta_j^r
=
\log
\frac{
P_j^r(y'_j)
}{
Q_j^r(y'_j)
}
=
\log
\frac{
\pi_{\theta_k}(y'_j\mid x,y'_{<j})
}{
\pi_{\theta_k}(y'_j\mid x,y_{<b(j)})
}.
\]

Interpretation:

- \(\Delta>0\): token is more supported by its own trajectory prefix.
- \(\Delta\approx0\): token is weakly discriminative.
- \(\Delta<0\): token is more supported by the competing prefix.

---

## 6. Centered Optimal \(f\)-Critic

From the variational representation of \(f\)-divergence, the optimal critic is:

\[
r^*(z)
=
f'\left(\frac{P(z)}{Q(z)}\right).
\]

CO-CRAFT uses the centered critic:

\[
a_f(\Delta)
=
f'(e^\Delta)-f'(1).
\]

This centering ensures:

\[
\Delta=0
\quad\Rightarrow\quad
a_f(\Delta)=0.
\]

So non-discriminative tokens receive neutral importance.

For chosen and rejected tokens:

\[
a_t^c=a_f(\Delta_t^c),
\qquad
a_j^r=a_f(\Delta_j^r).
\]

---

## 7. Token Weights

The positive token weights are:

\[
g_t^c
=
\mathrm{NormClip}
\left(
\exp
\left[
\mu\cdot
\mathrm{clip}(a_t^c,L,U)
\right]
\right),
\]

\[
g_j^r
=
\mathrm{NormClip}
\left(
\exp
\left[
\mu\cdot
\mathrm{clip}(a_j^r,L,U)
\right]
\right).
\]

A practical definition of \(\mathrm{NormClip}\) is:

\[
\mathrm{NormClip}(\tilde g_t)
=
\mathrm{clip}
\left(
\frac{
\tilde g_t
}{
\frac{1}{T}\sum_{i=1}^{T}\tilde g_i+\epsilon
},
g_{\min},
g_{\max}
\right).
\]

Recommended defaults:

\[
\mu\in\{0.5,1.0\},
\qquad
L=-2,
\qquad
U=2,
\]

\[
g_{\min}=0.25,
\qquad
g_{\max}=4.0.
\]

All weights should be computed under `no_grad` and detached.

---

## 8. Weighted Scores

The weighted chosen score is:

\[
\widetilde S_c
=
\sum_{t=1}^{T}
g_t^c
\beta
\log
\frac{
\pi_\theta(y_t\mid x,y_{<t})
}{
\pi_{\theta_k}(y_t\mid x,y_{<t})
}.
\]

The weighted rejected score is:

\[
\widetilde S_r
=
\sum_{j=1}^{T'}
g_j^r
\beta
\log
\frac{
\pi_\theta(y'_j\mid x,y'_{<j})
}{
\pi_{\theta_k}(y'_j\mid x,y'_{<j})
}.
\]

The final CO-CRAFT-Token loss is:

\[
\mathcal L_{\mathrm{CO\text{-}CRAFT\text{-}Token}}
=
\mathbb E
\left[
\ell
\left(
\widetilde S_c
-
f^*(\widetilde S_r)
-
\widetilde v
\right)
\right].
\]

Here \(\widetilde v\) is the weighted sequence-KL correction.

---

## 9. Divergence Choices

Let:

\[
\Delta=\log(P/Q).
\]

### KL

\[
f(u)=u\log u,
\qquad
f'(u)=\log u+1.
\]

\[
a_{\mathrm{KL}}(\Delta)=\Delta.
\]

Therefore:

\[
g_t\propto \exp(\mu\Delta_t).
\]

This recovers PRISM-style weighting.

### Jensen-Shannon

\[
a_{\mathrm{JS}}(\Delta)
=
\log2-\log(1+e^{-\Delta}).
\]

JS is bounded and stable, so it is the recommended default.

### Hellinger

\[
a_{\mathrm{Hel}}(\Delta)
=
1-e^{-\Delta/2}.
\]

Hellinger is conservative and stable.

---

## 10. Algorithm

```text
Input:
    SFT data D = {(x_i, y_i)}
    frozen self-play model pi_theta_k
    trainable model pi_theta
    divergence f, conjugate f*, derivative f'
    beta, mu, L, U, g_min, g_max

For each self-play pair (x, y, y'):

    1. Forward pi_theta_k on chosen sequence (x, y).
       Get own-prefix log-probs for chosen tokens.

    2. Forward pi_theta_k on rejected sequence (x, y').
       Get own-prefix log-probs for rejected tokens.

    3. Build token alignment maps:
           a(t): chosen token -> rejected prefix position
           b(j): rejected token -> chosen prefix position

    4. For each chosen token y_t:
           Delta_t^c =
               log pi_theta_k(y_t | x, y_<t)
             - log pi_theta_k(y_t | x, y'_<a(t)>)

           a_t^c = f'(exp(Delta_t^c)) - f'(1)

           raw_g_t^c =
               exp(mu * clamp(a_t^c, L, U))

    5. Normalize and clip all chosen raw weights.

    6. Repeat steps 4-5 for rejected tokens.

    7. Detach all weights.

    8. Compute weighted scores:
           S_c_tilde, S_r_tilde

    9. Optimize:
           ell(S_c_tilde - f*(S_r_tilde) - v_tilde)
```

---

## 11. Implementation Checklist

- Compute weights with frozen \(\pi_{\theta_k}\).
- Use `torch.no_grad()` for weight computation.
- Detach all weights before training.
- Mask prompt tokens, padding tokens, and special tokens.
- Normalize weights to mean one per sequence.
- Clip weights into a safe range.
- Clamp \(f^*\) input when the conjugate has limited domain.
- Use JS as the default divergence.
- Consider JS \(\rightarrow\) KL schedule for later self-play iterations.

## 12. Paper-Ready Paragraph

```latex
\paragraph{Token-level conjugate-originated weighting.}
CRAFT first introduces sequence-level asymmetry by transforming the rejected score with the Fenchel conjugate $f^*$. To make token importance consistent with the same divergence principle, we derive token weights from the optimal $f$-critic. For a chosen token $y_t$, we compare its probability under the chosen prefix and the aligned rejected prefix using the frozen self-play model $\pi_{\theta_k}$:
\[
\Delta_t^c =
\log
\frac{
\pi_{\theta_k}(y_t\mid x,y_{<t})
}{
\pi_{\theta_k}(y_t\mid x,y'_{<a(t)})
}.
\]
The variational representation of $f$-divergence gives the optimal critic $f'(P/Q)$. We therefore transform the log-ratio using the centered critic
\[
a_f(\Delta)=f'(e^\Delta)-f'(1),
\]
which assigns zero offset to non-discriminative tokens. The final token weights are obtained by exponentiating, normalizing, and clipping the centered critic. These detached weights are used to form weighted chosen and rejected scores before applying the outer CRAFT objective.
```
